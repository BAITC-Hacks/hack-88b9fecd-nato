# AI Sana — демонстрация за 5 минут

## Подготовка

Запустите `npm run dev`, откройте http://127.0.0.1:3000. Роль «Бизнес», профиль «Мастерская «Дело»». При необходимости используйте явный сброс демо-данных. Для гарантированного офлайн-сценария задайте `AI_MODE=fallback` перед запуском сервера. Исходный `.env` перезаписывать не нужно. С OpenAI вопросы могут отличаться — ответы вводите по смыслу, недостающие поля заполните в карточке.

## 0:00–0:35 — реальная потребность

Покажите кабинет и скажите: «Рейтинг оценивает готовность задачи к работе, а не популярность компании. Даже слабая опубликованная задача доступна всем командам».

Нажмите «Создать задачу», вставьте:

> Нужна система для учёта заявок клиентов нашей мастерской.

Нажмите «Продолжить», затем «Проанализировать описание». Покажите честный индикатор OpenAI или резервного режима. На слабом описании предварительный рейтинг — 10: известна только потребность.

## 0:35–1:40 — вопросы и факты

Подготовленные ответы для семи полей (в fallback вопросы идут в этом порядке):

| Поле | Ответ |
| --- | --- |
| Контекст | Сейчас администратор записывает заявки в бумажный журнал. Мастера узнают об изменениях по телефону. |
| Пользователи | Администратор мастерской и пять мастеров. |
| Данные и материалы | Обезличенные примеры 30 заявок в CSV и перечень услуг мастерской. |
| Источник и доступ | Владелец передаст CSV после первого созвона. |
| Ожидаемый результат | Веб-прототип реестра заявок с поиском, назначением мастера и статусами. |
| Критерии успеха | Проверка: создать заявку, назначить мастера, найти её поиском и закрыть; сценарий проходит без ошибок. |
| Ограничения | Прототип за 3 недели; без персональных данных реальных клиентов. |

Нажмите «Сформировать карточку». Название, отрасль и контакты могут оставаться пустыми: AI не должен придумывать их.

## 1:40–2:35 — прозрачный рост рейтинга

Введите:

- Название: **Реестр заявок мастерской**.
- Отрасль: **Услуги**.

Покажите рейтинг **90** и раскройте «За что начислены баллы» у связи с бизнесом. Добавьте:

- Контакт бизнеса: **workshop@example.com** → рейтинг **95**.
- Взаимодействие: **Созвон по вторникам и ответы на вопросы в рабочем чате в течение двух дней.** → **100**.

Объясните: «Это предварительный рейтинг. В каталоге пока ничего не изменилось». Очистите контакт — рейтинг станет 95, верните его — снова 100. Нажмите «Сохранить и подтвердить изменения»: подтвердится 100, прирост к прошлому официальному значению 0 составит +100. Это не +90: первоначальные 10 были только предварительными. При повторном подтверждении прирост равен 0.

Нажмите «Опубликовать задачу». Карточка появилась в каталоге. При равном рейтинге старые задачи стоят раньше новых.

## 2:35–3:35 — команда выбирает сама

Выберите роль «Студенческая команда», профиль «Код будущего». В каталоге найдите «Реестр заявок мастерской», откройте карточку.

Отклик:

- Идея решения: **Сделаем реестр заявок с поиском, фильтрами статусов и назначением мастера.**
- План: **Уточним процесс на интервью, соберём прототип, проверим сценарии с администратором и передадим инструкцию.**
- Предполагаемый срок: **Прототип за 3 недели.**
- Ссылка: **https://example.com/workshop-prototype** (синтетическая).

Нажмите «Отправить отклик». Откройте «Мои отклики», покажите «На рассмотрении». Обновите страницу и снова откройте раздел: отклик сохранён.

## 3:35–4:25 — бизнес принимает решение

Переключитесь на «Бизнес», «Мастерская «Дело»», откройте «Отклики команд», выберите задачу. Сравните идею, план, срок, навыки и ссылку. Нажмите «Принять».

Скажите: «AI не выбирает победителя. Бизнес может принять несколько команд или ни одной. Другие отклики не отклоняются автоматически».

Вернитесь в студенческую роль, «Мои отклики»: статус «Принят».

## 4:25–5:00 — подтверждённый прогресс

В принятом отклике раскройте «Отправить результат этапа»:

- Что сделано: **Подготовлен прототип реестра, реализованы поиск и смена статуса заявки.**
- Ссылка: **https://example.com/workshop-milestone**.

Отправьте результат. В роли бизнеса нажмите «Подтвердить этап · +25». В студенческом кабинете появятся 25 баллов. Подчеркните: «Это отдельные баллы команды за проверенный результат. Они не повышают рейтинг задачи; повторное подтверждение не даёт ещё 25».

## Дополнительные проверки для жюри

1. В каталоге выберите готовность «Черновик». Исходная задача мастерской с 10 баллами видна, форма отклика доступна.
2. В исходной задаче мастерской примите оба начальных отклика: это допустимо.
3. Измените опубликованную карточку и сохраните только черновик: публичная версия останется прежней.
4. Перезапустите сервер: подтверждённые карточки, отклики и решения сохранятся.
5. Покажите 16 автоматических тестов бизнес-логики и отдельный браузерный сценарий; фактические результаты записаны в STATUS.md.
