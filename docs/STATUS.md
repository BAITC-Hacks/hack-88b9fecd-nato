- Русский кабинет бизнеса, демо-роли и профили, конструктор, редактирование и подтверждение карточки, отдельная публикация.

- Каталог всех опубликованных задач, фильтры и поиск, отклики без квот, независимый ручной выбор нескольких команд.
- Результаты этапов, ручное подтверждение и 25 баллов команде без повторного начисления.
- JSON-хранилище с межпроцессной блокировкой и атомарной записью; 5 задач всех четырёх уровней, 5 команд, 5 откликов; сброс с подтверждением.
- OpenAI SDK Responses API, Zod, проверка цитат, timeout и fallback; README и пятиминутный сценарий.

## Известные ограничения и блокеры

Блокеров основного демо и известных воспроизводимых ошибок после исправлений нет. Исправлен обнаруженный браузером дефект сравнения Origin: Next.js нормализовал 127.0.0.1 в localhost.

- Демо-профили не являются авторизацией; приложение предназначено для локального показа.
- Рейтинг — открытая эвристика заполненности, не проверка достоверности фактов.
- Неподтверждённые формы нужно сохранять вручную перед уходом; ответы в форме не автосохраняются.
- После аварийного завершения во время транзакции может потребоваться удалить оставшийся `.lock` **только после остановки всех серверов**, см. README.
- Локальный Node находится в `.tools`, отсутствует в системном PATH. Команды из README позволяют запуск без системной установки. tsx/браузер в ограниченной Windows-среде запускались с обычным разрешением вне песочницы.
- Установленный Edge не запустился; успешный E2E выполнен в отдельно установленном Chromium.

## Отложено

Необязательные рекомендации команд, realtime, отдельные URL карточек, автосохранение всех ответов. Аутентификация, облачная БД и деплой выходят за рамки локального MVP.
